# 📝 TEMPLATE BUILDER - Hướng Dẫn Tạo Template Mới

**Mục đích**: Khi research + sản xuất một thể loại mới thành công, tạo template để tái sử dụng

---

## 🎯 KHI NÀO TẠO TEMPLATE MỚI?

| Điều kiện | Action |
|-----------|--------|
| Làm ≥3 video cùng thể loại | → Xem xét tạo template |
| Pattern rõ ràng và lặp lại | → Nên tạo template |
| CHỦ yêu cầu làm thêm loại này | → Tạo template |
| Structure phức tạp, dễ quên | → Tạo template để nhớ |

---

## 🔄 QUY TRÌNH TẠO TEMPLATE

```
1. Hoàn thành project mới với thể loại chưa có template
2. Đánh giá: Structure có hiệu quả không?
3. Nếu YES → Tạo template theo format trên
4. Lưu vào: 02_Universal/Templates/[Tên_Thể_Loại].md
5. Update README nếu cần
```
