## 🔑 QUY LUẬT VISUAL VARIETY

### 3 thứ THAY ĐỔI mỗi outfit:
1. **Bottom** — khác hoàn toàn (váy/quần/jeans)
2. **Kiểu tóc** — xen kẽ (ponytail ↔ bun ↔ xõa)
3. **Accessories** — khác nhau (túi/belt/jewelry/sunglasses)

### 3 thứ GIỮ NGUYÊN:
1. **Base item** (áo sơ mi trắng) — nhưng CÁCH MẶC có thể đổi
2. **Vị trí đứng** — cùng góc phòng
3. **Góc máy** — wide shot, fixed, eye-level

### Cách mặc base item (5 biến thể):
| Biến thể | Khi nào dùng |
|-----------|-------------|
| Tucked in (bỏ vào gọn) | Thứ 2-5 — professional/clean |
| Tied knot (buộc nút eo) | Thứ 6 — playful/trendy |
| Open as layer (mở ngoài) | Thứ 7 — casual/chill |
| Loosely tucked (bỏ lỏng) | CN — relaxed/feminine |
| Untucked (thả ngoài) | Hook — basic/lazy |
