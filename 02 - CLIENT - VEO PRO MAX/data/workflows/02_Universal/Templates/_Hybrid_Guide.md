# 🔀 HYBRID GUIDE - Hướng Dẫn Mix Templates

**Mục đích**: Khi topic kết hợp nhiều thể loại, cách mix templates hiệu quả

---

| Topic | Signals | Templates cần mix |
|-------|---------|-------------------|

## 📋 QUY TRÌNH HYBRID

```
STEP 1: IDENTIFY THEMES
─────────────────────────
Phân tích topic → Xác định:
• Primary Theme (chủ đạo)
• Secondary Theme(s) (phụ trợ)

Ví dụ: "Thực phẩm chửi người dùng"
• Primary: Health (thực phẩm, tác hại)
• Secondary: Drama (chửi mắng, conflict)


STEP 2: LOAD RELEVANT TEMPLATES
─────────────────────────────────
Load tất cả templates liên quan:
• Health_PMCS.md (cho cơ chế, hậu quả)
• Family_Drama.md (cho tone drama)


STEP 3: MIX ELEMENTS
────────────────────
Kết hợp elements từ mỗi template:

┌─────────────────────────────────────────────────────────────┐
│  ELEMENT        │  LẤY TỪ         │  GHI CHÚ               │
├─────────────────┼─────────────────┼────────────────────────┤
│  Characters     │  Primary        │  Thực phẩm nhân hóa    │
│  Tone/Style     │  Secondary      │  Drama, chửi mắng      │
│  Structure      │  Primary        │  PMCS (P→M→C→S)        │
│  Dialogue       │  Secondary      │  Villain đắc thắng     │
│  Conflict       │  Secondary      │  Đối đầu với người     │
│  Resolution     │  Primary        │  Giải pháp sức khỏe    │
└─────────────────────────────────────────────────────────────┘


STEP 4: CREATE HYBRID BIBLE
────────────────────────────
Tạo Bible với structure hybrid:
• Sections từ Primary template
• Tone và dialogue style từ Secondary
• Characters có đặc điểm của cả hai


STEP 5: APPLY UNIVERSAL RULES
─────────────────────────────
Vẫn tuân thủ 100%:
• E0-E32
• Voice format
• Zero text policy
• Sensitive words
```

## 🎬 VÍ DỤ THỰC TẾ

### Topic: "Bánh chưng hỏng chửi người ăn"

**Analysis:**
```
Primary: Health (bánh chưng hỏng, độc tố, tác hại)
Secondary: Drama (chửi mắng, villain tone)
```

**Hybrid Structure:**
```
Opening (Drama hook):
→ Bánh chưng hỏng xuất hiện với vẻ đắc thắng

Mechanism (Health content + Drama tone):
→ Villain bánh chưng tự hào kể về độc tố
→ "Ta chứa aflatoxin gấp 10 lần cho phép!"

Consequence (Health + Drama):
→ Bánh chưng cười ác khi thấy người ăn đau bụng
→ Split screen: cơ chế + triệu chứng

Solution (Health resolution):
→ Expert xuất hiện "đánh bại" villain
→ Cách nhận biết và phòng tránh
```

**Characters:**
```
Villain: Bánh Chưng Hỏng
• Visual: Màu xám, nấm mốc, ánh mắt ác
• Tone: Đắc thắng, cười ác, đe dọa
• Xưng: "Ta", "Bọn ta"

Victim: Người Ăn
• Visual: Gia đình VN bình thường
• Trạng thái: Từ khỏe → đau bụng

Expert: Bác Sĩ
• Visual: Áo trắng, nghiêm túc
• Vai trò: Giải thích + giải pháp
```

## 📊 MIX MATRIX

|-------------------------|-------|--------|--------|-------------|

## ⚠️ LƯU Ý QUAN TRỌNG

> [!IMPORTANT]
> **Primary quyết định:**
> - Story structure (PMCS, 3-Act, etc.)
> - Core message
> - Resolution type

> [!TIP]
> **Secondary bổ sung:**
> - Tone và style
> - Character personality
> - Dialogue patterns
> - Entertainment value

> [!WARNING]
> **Tránh:**
> - Mix quá nhiều themes (max 2-3)
> - Để Secondary lấn át Primary message
> - Làm mờ core value của video

## 🔄 AFTER HYBRID

Nếu hybrid này thành công và lặp lại nhiều lần:
→ Xem xét tạo template riêng cho combo này

Ví dụ:
- Health + Drama → `Templates/Villain_Food.md`
- Family + Educational → `Templates/Family_Learning.md`
