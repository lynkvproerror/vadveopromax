## 🚀 CÁCH SỬ DỤNG

### CHỦ chỉ cần nói:
```
"Làm video về [bất kỳ chủ đề nào]"

Ví dụ:
• "Làm phim siêu nhân Lego"
• "Làm video tình tay ba drama"
• "Làm phim con vẹt biết nói"
• "Làm video tác hại thức ăn nhanh"
• "Làm phim nhân vật mini battle"
```

### AI sẽ tự động:
```
1. RESEARCH: Phân tích chủ đề → Tìm trending → Xác định audience
2. ADAPT: Chọn story structure phù hợp (KHÔNG cứng nhắc A/B/C)
3. APPLY: Technical rules (E0-E32, voice, zero text, etc.)
4. CREATE: 5 files theo format chuẩn
5. QC: Check quality trước deliver
```

## ⚠️ RULES CHÍNH (Luôn áp dụng)

### Voice Format
```
✅ ĐÚNG: [Giọng: Miền Nam, 35 tuổi]
❌ SAI:  [Region: Nam] [Gender: Female] [Age: 35s]
```

### Zero Text Policy
```
✅ Kết thúc mọi prompt: no text, no subtitles, no labels, no watermarks
❌ KHÔNG text, số liệu, labels trong visual
```

### Dialogue
```
❌ KHÔNG: ? ! - 
❌ KHÔNG: Câu cụt < 5 chữ
✅ Mỗi câu ≤ 20 từ
```

### Sensitive Words
```
❌ chết, tử vong, giết
✅ hẹo, tiêu đời, tiêu diệt
```
