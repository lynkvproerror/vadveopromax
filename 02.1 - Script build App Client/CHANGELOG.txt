v2.3.13 — Project Builder I2V Frame Mode & Engine Retry Fix

🎬 Project Builder
• Thêm lựa chọn I2V Mode (Start only / Start + End) trong sidebar.
• Start only: chỉ dùng 1 ảnh đầu — giảm tải server, ít timeout.
• Start + End: dùng cặp ảnh liên tiếp cho dual-frame (_fl_ model) — chuyển cảnh mượt.
• Model tự động chuyển đúng (Single/Dual/Fast/LP) theo lựa chọn.

🔧 Engine & Retry
• Sửa lỗi task fail với INTERNAL error không được retry.
• INTERNAL error giờ được xử lý giống TIMED_OUT — tự động retry 2 lần trước khi fail.
• Cải thiện độ ổn định pipeline khi server VEO bị quá tải.
